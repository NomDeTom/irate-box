# Using the hub

*For everyone on the box's network.*

The hub is the front page of the box. It does not need an internet connection. The apps run on the box.

- **The tiles** open each app: drawing (Excalidraw), diagrams (Mermaid), the file drop, the offline library (Kiwix), shared notes (and, once signed in, a notebook of your own), calculators, chat, the App store (release files for phones) and more, as an administrator set them up. Some open for guests. Some open for signed-in users only and show a padlock.
- **The shoutbox and the board**: short messages, and threads, for everyone on the hub. Report any item that should not be there. An administrator decides.
- **The file drop**: leave files for others, and take theirs. A file can be locked to your browser. Other browsers cannot change or remove a locked file without the key.
- **👤 Sign in** if an administrator gave you an account, or if the box lets anyone create one. Select **Create account** to create one. Your account page has your own settings.
- **🛟 Help** says what each app is for.
- **The theme picker** at the top: light (☀️), dark (🌙) or **Auto** (as your device is set); and under 🎨, the colours: the **Box palette** (set by an administrator, the default), **Standard palette**, **Increased contrast**, or a theme of its own colours (E-ink, Cybercore). Your choice stays in your browser.

## Privacy

Without an account, a page asks for any name. The box does not check that name. With an account, your username identifies you.

HTTP does not encrypt traffic. Others on the same WiFi can read what you type. Use HTTPS for passwords and private information. The box's certificate page (`/certificate`) shows how to trust the box. Check that page before you trust the box.
