# Using the hub

*For everyone on the box's network.*

The hub is the box's front page. It needs no internet: everything here stays on the box, for the people around it.

- **The tiles** open each app: drawing (Excalidraw), diagrams (Mermaid), the file drop, the offline library (Kiwix), notes, calculators, chat and more, as the owner set it up. Some open for everyone, some for signed-in users only (with a padlock).
- **The shoutbox and the board**: short messages, and threads, for everyone on the hub. Report anything that shouldn't be there; the owner decides.
- **The file drop**: leave files for others, and take theirs. A file can be locked to your browser, so only you can change or remove it.
- **👤 Sign in** if the owner has given you an account, or if the box lets anyone make one. Your account page has your own settings.
- **🛟 Help** says what each app is for.

## Privacy

Pick any name a page asks for. Nothing is sent anywhere else. Without the padlock (HTTPS), anything you type can be read by others on the same WiFi: the box's certificate page (`/certificate`) shows how to get the padlock.
