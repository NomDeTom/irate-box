# Glossary

*Words that the box pages use.*

| Term | Definition |
|---|---|
| Access | Who can open an app or page: Guests, Users, Administrators or Disabled |
| Account | A user or administrator account that can sign in |
| Add-on | An extra that an administrator can add or remove: Kiwix, Notes, Syncthing and others |
| Administrator | A person with an administrator account. An administrator can change the box settings |
| Appearance | The icon, the label and the size of a tile, and the colours of the hub |
| Book | An offline reference in the ZIM format. Kiwix reads it |
| Cache | A local copy of a downloaded file that the box keeps |
| Discard | Throw away changes that you did not save |
| Doctor | A page that checks one part of the box, lists the problems and offers repairs |
| Guest | A visitor without an account |
| Hotspot | The WiFi network of the box |
| Hotspot service access | What guests on the hotspot can reach on the box (also called the floor) |
| Hub | The front page of the box and the program behind it |
| Initial setup | The state of a new box before an administrator account exists. Until an administrator creates the account, anyone on the network can open the administration pages |
| Install | Put a downloaded package or add-on into use |
| Mirror | A copy of a repository from another server, kept on the box |
| Recovery steps | The repairs of the network watchdog, from the lightest to the heaviest (also called the ladder) |
| Retention period | The time that the box keeps an item before it deletes it |
| Save | Keep the changes that you made |
| Sign in | Open a session with your account |
| Storage limit | The largest amount of storage that an item can use |
| Toolkit | A set of packages for one kind of job. Install it without internet if all its packages are in the cache |
| Updates | New versions of the box, apps, books and packages |
| User | A signed-in person who has an account |
| User data | Shared files, drawings, posts and repositories |
| Visibility | Who can see a tile on the hub |
