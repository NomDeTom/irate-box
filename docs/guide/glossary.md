# Words used here

*A few words the box's pages use.*

| Word | What it means here |
|---|---|
| Hub | the box's front page, and the program behind it |
| Admin | the owner, signed in with an admin account |
| Add-on | an extra the owner can add or remove: Kiwix, Notes, Syncthing… |
| Book | an offline reference in the ZIM format, read with Kiwix |
| Doctor | a page that looks at one part of the box and says what's wrong, with the fix |
| Hotspot | the box's own WiFi |
| Floor | what guests on the hotspot can reach on the box |
| Ladder | the network watchdog's repairs, from the lightest to the heaviest |
| Mirror | a copy of a repository from elsewhere, kept on the box |
| Toolkit | a set of packages for one kind of job, installable with no internet |
| First use | a new box before its admin account is made: its admin pages open to anyone |
