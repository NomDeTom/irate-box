New boards

A new board joins your network with the choices set here: its network, its accounts, its name. A Lyra, a Banana Pi or another Armbian board can be set up, over its setup hotspot, its serial console, its SD card or its default password on a cable. Power one new board at a time, near this box: until it is set up, anyone in range can set it up instead.
