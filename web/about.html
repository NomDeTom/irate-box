ℹ️ About this box

Irate-Box: an offline hub, in the spirit of PirateBox.

What it is

A small board running its own hub: a shoutbox, a board, a file drop, drawing and diagram tools, an offline library and more, for the people around it, with no internet needed. Its version: ….

Licences

The original PirateBox was free software under the GPL, and this follows it. Every file says which licence it is under, in its first lines (SPDX); the full texts are in the source's LICENSES/ folder.

  • GNU AGPL-3.0-or-later the hub itself: its server, pages, root helper, doctors, librarian and installer. Because you use it over the network, you can have its source: see below.
  • GNU GPL-3.0-or-later the git servers' page, builds on push, and books from USB sticks.
  • MIT small, self-contained pieces others may want to reuse (the network inventory, the clock-module driver, the device locks, configuration files and app manifests), and the QR-code library (Kazuhiko Arase).
  • CC BY-SA 4.0 the documentation, including this page and the help page.

Versions published before October 2026 were in the public domain (the Unlicense), and stay so.

This box's own source

Exactly the code running here, three ways, none of which need the internet:

  • Download it as one file (a .tar.gz).
  • Browse it on the box's git server, or clone it: git clone http://…/git/irate-box-source.git
  • The file drop always holds a copy (📌).

Online, the project lives at github.com/NomDeTom/irate-box.

The programs it runs

These are separate programs with their own licences, run side by side with the hub. Where an app came as a bundle, its list of the licences of everything inside is next to it (its THIRD-PARTY-NOTICES file), and names the exact source it was built from.

  • Excalidraw (drawing), MIT: notices
  • Mermaid live editor (diagrams), MIT: notices
  • Meshtastic web flasher GPL-3.0: notices and its source
  • Meshtastic firmware (in the flasher's mirror), GPL-3.0: source at github.com/meshtastic/firmware, tagged with each version
  • Kiwix (the offline library), GPL-3.0
  • nginx (or Caddy, Apache-2.0), BSD-2-Clause; cgit GPL-2.0; ttyd MIT; SilverBullet MIT; Syncthing MPL-2.0; Mosquitto EPL-2.0 / EDL-1.0
