ℹ️ About this box

Irate-Box: an offline hub, in the spirit of PirateBox.

What it is

Irate-Box is an offline hub. It serves these pages over its own network. The administrator selects which apps are enabled. Apps can include a shoutbox, a board, a file drop, drawing and diagram tools, and an offline library. Some apps can need internet access. Version: ….

Licences

The original PirateBox was free software under the GPL. This box follows it. Every file names its licence in its first lines (SPDX). The full texts are in the LICENSES/ folder of the source.

  • GNU AGPL-3.0-or-later The hub itself: its server, pages, root helper, doctors, librarian and installer. Anyone who uses the hub over a network can get its source. See below.
  • GNU GPL-3.0-or-later The git servers' page, builds on push, and books from USB drives.
  • MIT Small, self-contained pieces that others can reuse: the network inventory, the clock-module driver, the device locks, configuration files and app manifests. Also the QR-code library (Kazuhiko Arase).
  • CC BY-SA 4.0 The documentation, including this page and the help page.

This box's own source

This is the exact code that runs on this box. There are three routes. None of them needs internet access.

  • Download source archive One .tar.gz file.
  • Browse source On the box's git server. To clone it, run: git clone http://…/git/irate-box-source.git
  • File drop If File drop is enabled, it holds a copy (📌). An administrator can delete that copy.

The project is online at github.com/NomDeTom/irate-box.

Included programs

These are separate programs with their own licences. They run beside the hub. Each can be installed or not installed on a box. If an app came as a bundle, its THIRD-PARTY-NOTICES file is next to it. That file lists the licences of everything inside the bundle and names the exact source.

The apps

  • Excalidraw Drawing, when installed. MIT: notices
  • Mermaid live editor Diagrams, when installed. MIT: notices
  • ESP Web Tools The web flasher's install button (ESPHome, with Espressif's esptool-js and Lit inside), when installed. Apache-2.0, with the parts inside it under their own licences: notices
  • FreeOCD WebDebugger The flashing tools' ARM flasher (FreeOCD, with Arm's DAP.js inside), when installed. BSD-3-Clause, with DAP.js under MIT: its notices.
  • Meshtastic web flasher Flashing radios over USB, as a download, when installed. GPL-3.0: notices and its source
  • Meshtastic firmware In the flasher's mirror, if an administrator keeps one. GPL-3.0. The source is at github.com/meshtastic/firmware, tagged with each version.
  • M-PWRD logo The Meshtastic tile's picture, from github.com/meshtastic/design. GPL-3.0. Meshtastic® is a registered trademark of Meshtastic LLC. Its use here does not imply endorsement or sponsorship by the Meshtastic Project.
  • Kiwix The offline library, when the box has books. GPL-3.0

Programs that run the apps

  • nginx The web server in front of everything. The box uses it unless an administrator selected Caddy. BSD-2-Clause
  • Caddy The other web server. The box uses it only if an administrator selected it or nginx could not be installed. Apache-2.0
  • Python Runs the hub itself. PSF-2.0
  • git Behind the git servers (git http-backend). GPL-2.0
  • cgit The git servers' web pages. GPL-2.0
  • fcgiwrap Runs git and cgit for the web server. MIT

Add-ons, when an administrator adds them

  • ttyd The terminal (a shell in the browser), behind the administrator sign-in. The installer always installs it. It runs only after an administrator adds it. MIT
  • SilverBullet Notes. MIT
  • Syncthing Synchronizes folders with the administrator's devices. MPL-2.0
  • Mosquitto The MQTT broker for Meshtastic nodes. EPL-2.0 / EDL-1.0
  • ngIRCd The IRC server for chat. GPL-2.0-or-later
  • InspIRCd The alternative IRC server for chat. GPL-2.0-only
  • excalidraw-room Live collaboration on the whiteboard. MIT
  • Node.js Runs the collaboration relay. MIT
