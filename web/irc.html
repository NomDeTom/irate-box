💬 IRC chat

Real-time chat in any IRC app, for devices that can reach this box.

The box runs a small IRC server. This page is not the chat. It shows the connection details for your IRC app. Install an IRC client on your device before you use chat offline.

Connect

🖧
Server: this box

Port 6667. This server does not encrypt traffic. Other devices on the network can read it. Disable TLS/SSL in your app, because the server does not support it. Enter no password.

#️⃣
Channel: #lobby

Select a nickname. Join #lobby. Your app can open the channel from this link: irc://this box:6667/lobby. If nothing happens, enter the server and the channel in the app.

Example IRC apps

  • Android: Goguma, Revolution IRC
  • iPhone and iPad: an IRC app from the App Store
  • Windows, Mac and Linux: HexChat, Halloy
  • In a terminal: WeeChat, irssi

Privacy and message history

  • This IRC server has no accounts. A nickname is yours only while you are connected. Anyone can use it afterwards.
  • The server does not encrypt traffic. Anyone who can reach the server can read the chat. Normally this is every device on this box's network. Remote access or routing can add other devices. Do not send anything that must stay secret.
  • The server keeps no message history. You see only what people say while you are connected.
  • Other people in the chat see a made-up name for your device, not its address. The same device keeps the same name until the box restarts. This does not make you anonymous.
  • #lobby always exists. A channel that you create is removed when the last person leaves it.
  • This server has no moderators. An administrator can disable the chat in Administration.
