Set up

Step 1 of 5: create the administrator account for this box.

This box has no administrator account yet. The person who creates the administrator account here controls the box. The account opens the administration pages, the terminal at /term and Syncthing at /sync. Later, sign in with it where everyone signs in (👤 Sign in, at the top of the hub).

Until the account exists, anyone on this network can create it and become the administrator. Create the account now. If you are a guest and not the administrator, do not use this page.

After this step, the administration pages guide you through the rest: the box's own sign-in for scripts, how guests reach the box, what the box exposes, add-ons and books. You can skip each step and do it later.

This page is open over HTTP. Other devices on this network can read a password that you type here. Use one of these safer ways:

  • Open the same page over HTTPS. If the browser warns that the connection is not private, first install the box's certificate on this device: the certificate page.
  • At the box console over SSH, run: sudo /opt/irate-box/irate-box hub_control set-admin NAME

If you lose the password, run this command at the box console over SSH: sudo /opt/irate-box/irate-box hub_control set-admin NAME It sets a new password for the same username or for a new administrator.
