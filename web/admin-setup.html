Set up

Step 1 of 5: make the admin account for this box.

This box has no admin yet. Whoever makes the admin account here owns the box: it opens the admin page, the terminal at /term and Syncthing at /sync. Sign in with it later where everyone signs in (👤 Sign in, at the top of the hub).

Anyone on this network can open this page until the account is made, so make it now. If you are a guest, not the owner, please leave this alone.

After this, the admin page takes you through the rest: how guests reach the box, what it exposes, add-ons and books. Each of those can be skipped and done later.

Lost the password later? From the box's own console: sudo /opt/irate-box/irate-box hub_control reset-password brings this page back; making the account again with the same name sets its new password.
