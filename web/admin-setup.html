Set up

Step 1 of 5: make the admin account for this box.

This box has no admin yet. Whoever makes the admin account here owns the box: it opens the admin page, the terminal at /term and Syncthing at /sync. Sign in with it later where everyone signs in (👤 Sign in, at the top of the hub).

Until the account is made, anyone on this network can use the box's admin pages, so make it now. If you are a guest, not the owner, please leave this alone.

After this, the admin page takes you through the rest: how guests reach the box, what it exposes, add-ons and books. Each of those can be skipped and done later.

This page is open over plain HTTP: a password typed here crosses the network where anyone on it can read it. Set it a safer way:

  • over HTTPS, if this box has it on: the same page over HTTPS;
  • or at the box's console, over SSH: sudo /opt/irate-box/irate-box hub_control set-admin NAME.

Lost the password later? At the box's own console, over SSH: sudo /opt/irate-box/irate-box hub_control set-admin NAME sets a new one (the same name, or a new admin).
