⚡ Web flasher

Put Meshtastic on an ESP32 radio from this browser, over USB.

Looking…

    Plug the radio in with a data cable, press Install and choose its port. A first install erases the radio (its settings and messages go); the box asks first. nRF52 and RP2040 radios take a UF2 file dragged onto the drive they show when plugged in: those are among the Firmware Factory's downloads on the hub's front page.

    The Meshtastic web flasher is here too, as one file to save and open from your downloads: download it.

    The install button is ESP Web Tools (ESPHome, Apache-2.0). Its notices.
