⚡ Web flasher

Install Meshtastic on an ESP32 radio from this browser over USB.

Loading firmware list

    Connect the radio with a USB data cable. Select Install. Select the serial port. A first install erases the radio. This deletes the settings and messages on the radio. The installer asks for confirmation before it erases the radio.

    Some nRF52 and RP2040 radios use a UF2 file. Put the radio in its bootloader mode. The radio then shows a USB drive. Copy the UF2 file onto that drive. Some of the Firmware Factory downloads on the hub page are UF2 files.

    The Meshtastic web flasher is also available as one file. Download it, save it, and open it from your downloads folder: Download Meshtastic web flasher.

    The built-in flasher uses ESP Web Tools (ESPHome, Apache-2.0). Its notices.
