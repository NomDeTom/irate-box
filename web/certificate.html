What installing it does

The box made its own certificate authority (CA). If you install the CA, your device trusts the box's HTTPS pages. Other devices on the same network then cannot read or change what you send to the box over HTTPS. This includes the administrator password.

The CA is for this box only. It covers the box's names (). It also covers the addresses the box had when the certificate was made, on the hotspot network and on the home or office network. The certificate itself limits the CA to these names and addresses. A client that enforces these limits does not trust the CA for other sites. Not every client enforces them. Someone who takes control of the box can use the CA to impersonate another device on those networks. Install the CA only if you trust this box and its administrator.

You do not need the certificate to use the box. If an administrator has not disabled HTTP, every page also works over HTTP. Other devices on the same network can read HTTP traffic.
