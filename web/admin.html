Administration

Settings and services for this box.

This box has no administrator account. Anyone on this network can create one until you do. Set up this box over HTTPS, or at the console over SSH.

      Add-ons
      
          
      
            The hub works without these add-ons. Install an add-on to start its
            service. Remove it to stop its service and uninstall the service.
            Removal keeps its data. Install the add-on again to use that data.
            Installation can take several minutes on this board. The installer
            restarts the hub server during the installation.
          
      
          
      
          
      
            
            
      
          
      
          
      
            
              Installer output
            
            
      
          
      

          
      Web add-ons
      
          
      
            Web add-ons run in the visitor's browser. The box adds them without
            an installer and without a restart. Each add-on has its own address
            (this box, port 8090). The box prevents
            an add-on from opening the administration pages. An add-on can reach
            the services that its manifest declares, such as the MQTT broker. A
            new add-on is disabled. Select Access to give it to
            guests, users or administrators. The Apps list on this page keeps
            the add-on current, at the commit that the box's code checked,
            unless you select the newest.
          
      
          
      
          
      The catalogue
      
          
      
            The box offers these add-ons. Each add-on is pinned to a commit that
            the box checked.
          
      
          
      
          
      
            
              Add one by pasting its manifest
            
            
      
              
      
                ⚠️ Add a pasted manifest only if you have read it and you
                  trust its author.
              
      
              
      
                Nobody else checks a pasted manifest. The box downloads someone
                else's code. The box serves that code under its own name to
                everyone on the box's network who opens it. The code can show
                anything and ask for anything. It can send what people type to
                the services that its manifest declares. The box prevents it
                from opening the administration pages. If you are not sure, use
                the catalogue.

            The box's own sign-in, for scripts: the user admin and

            Recovery and monitoring
          
      
          
      
            Set how long crash snapshots are kept and when the box restarts
            after a freeze. The
            Box doctor shows the results.
          
      
          
          
      
            
      
              
      SD card writes
      
              
      
                An SD card wears with every write. The box writes a file only when
                it changes. It keeps live reports in memory. It adds to histories
                and does not rewrite them. The box can write less often. A crash
                or power failure can then lose changes made since the last write.
                Select how many changes the box can lose. At every level, the box
                writes user data and settings as they change.
              
      
              
      
              
      
              
              
      
                
                  System write settings
                
                
      
                  These settings change the system's configuration. Each one is
                  a file of irate-box's, removed again when you select the first
                  option. The record in
                  Box doctor → SD card writes shows the
                  effect of each change.
                
      
                
      
                
      
                
      
                
      
                  Always on: irate-box's own package runs keep apt's cache in
                  memory, the toolkits share one package list update a day and
                  download only the packages that changed, and the box writes a
                  file only when it changes.
                
      
              
      
            
      
            
            
      
              
      
                Automatic recovery
              
      
              
      
                Set crash snapshot retention and frozen-system restart. The uplink
                watchdog repairs the box's network connection and reboots the box
                for it:
                Network → Network recovery.

                are written under /etc/hub/ab. Nothing repartitions or reboots now: a fresh
                install or an offline repartition applies them, and the boot chain is confirmed on the board first.

      Firmware
      
          
      
            Store Meshtastic releases on the box for the web flasher. You can
            then flash a radio without internet access. The box stores every
            board unless you select boards (about 600 MB for each release).
            Clear All boards and select your boards to store only those (a few
            MB each, for each release). The box checks for new releases as often
            as you set below, when it has internet access. The firmware source
            code is a mirror like any other repository (Git → Mirrors). The
            build cache is with the builds (Git → Builds). To build your own
            firmware for boards that a release does not cover, or from a fork,
            use the Firmware Factory.

                Source access: GitHub token and rate limit
                
              
              
        GitHub token
        
              
        
                Use a token only for "GitHub Actions artifacts". GitHub requires
                a sign-in to download them, also from public repositories. A
                fine-grained token with read-only access to public repositories
                is enough. The box stores the token. Only the hub can read it.
                The page never shows it again.
                
              
        
              
        
                
                
        
                  
                  
                
        
              
        
              
        
                Adapt to the rate limit
              
        
              
        
                GitHub lets this box send 60 requests an hour without a token
                and 5000 with a token. Adapt asks GitHub for its request limit.
                The librarian then keeps its scheduled checks to a budget just
                under that limit. When the hourly budget is spent, the checks
                wait. If GitHub refuses several requests in a row, the box
                halves the budget. After a run with no refusals, the box raises
                the budget again. Adapt works with or without a token.

                to a policy (Mirrors, below). It is read-only here.

            Firmware Factory
          
          
          
          
            Build Meshtastic firmware on this box. The source is the box's own
            copy: a mirror, or an administrators-only repository such as a fork.
            Select a release or a branch, then select the boards. Builds run one
            at a time at the lowest priority, as the builder (Git → Builds). The
            box records the time, memory, disk and heat of each build. The
            estimates below come from these records. The first build of a family
            downloads its toolchain. After that download, builds of that target
            need no internet access. Other targets in the family can need more
            downloads.

            the finished builds. It also holds all decisions about building and
            scheduling. The builds use the box's own copies of the firmware
            source: a mirror under Git → Mirrors, or an
            administrators-only repository on the Git page.

                  Network terms
                
                
                  
                  
                  Client
                  
                  
                  
                    The box joins your WiFi as a laptop does. This is the box's
                    way to your network and the internet.
                  
                  
                  
                  Hotspot
                  
                  
                  
                    The box's own WiFi network. Guests join it (an "access
                    point").
                  
                  
                  
                  
                    Concurrent client and hotspot
                  
                  
                  
                  
                    Some radios can serve the client connection and the hotspot
                    at the same time. The hotspot is a second network.
                  
                  
                  
                  
                    Exclusive hotspot radio
                  
                  
                  
                  
                    This radio can do one task only. To run the hotspot, the box
                    must leave your WiFi.
                  
                  
                  
                  Channel
                  
                  
                  
                    The part of the WiFi band that a network uses. A radio that
                    can use one channel at a time makes its hotspot follow the
                    channel of your WiFi.
                  
                  
                  
                  
                    Connection manager
                  
                  
                  
                  
                    The program on the box that manages the connection of a
                    device (NetworkManager, wpa_supplicant, …). irate-box asks
                    that program and does not take control.
                  
                  
                  
                  Signal
                  
                  
                  
                    How strongly the box receives your WiFi, in dBm. A value
                    closer to 0 is stronger. About −50 is excellent, −70 is
                    weak, −80 is barely usable.

                  Hotspot status
                
                  
                
                  
              
                  
              
                  The hotspot
                  
              
                  
                The hotspot is the box's own WiFi network for guests. Its
                address is 192.168.4.1. In captive-portal DNS mode, every name
                leads to the hub. The box adapts to its radios. It uses a
                separate radio if one exists. If the radio supports it, the
                hotspot runs on its own channel beside your WiFi. Otherwise it
                follows the channel of your WiFi. Select below how guests join:
                open or encrypted.
              
                  
              
                  
                Checking…
              
                  
              
                  
                
                
                
                
                
                
                  
                  
                  
                
              
                  
              
                  

              
                  
                Hotspot security
              
                  
              
                  
                The hotspot can be open or encrypted. An open hotspot lets
                anyone join. An encrypted hotspot prevents a person who listens
                nearby from reading what guests do. Encryption excludes older
                devices. The choice applies the next time you switch the hotspot
                on above. That section also shows what the radios support. This
                is a setup decision, and the setup tour links here.
              
                  
              
                  
              
                  
                
                  
                  
                  
                
                  
                
                
                  
                  
                
                
              
                  
              
                    
              
                    
              
                    
              
                    
                Guest internet access
              
                    
              
                    
                This setting decides whether guests on the hotspot can use the
                box's connection to reach the internet. The levels run from no
                access to full access. The default is the safest. Each level
                says what it opens. Guest traffic leaves as the traffic of the
                box, so what guests do online comes from your connection. At
                every level, the box keeps guests out of your own network and
                the box's Tailscale. It lets them out by the hardware address of
                their device. It does not let them look up names before they
                pass the sign-in page. You can turn off each of these on
                Security. The doctor warns while one is
                off.

            Visitor data
            
                    
              For the People tile, the box counts different devices today and
              this week. It never records who they were.
            
                    
            
                    
              
                How the box counts devices
              
              
                    
                A helper reads the network addresses of the devices that the box
                has seen. It hashes each address with a random salt for the day
                and a random salt for the week. The helper holds the salts only
                in memory and discards them when the day or week ends. The box
                writes only the two numbers, and deletes them at reboot. Phones
                that use a random address can count more than once, so the
                numbers are approximate. If you turn this off, the helper does
                not run. Signed-in names show only if each person lets the box
                show it on their account page.
              
                    
            
                    
            
                    
              
            
                    
            
                    
          
                    
          
                    
            HTTP / HTTPS
            
                    
              The box can serve every page over HTTPS too, with a certificate of
              its own. Select below whether plain HTTP remains available.
            
                    
            
                    
              
                How the box's certificate works
              
              
                    
                Phones and computers that install the box's certificate (from
                /certificate) then use HTTPS when
                they connect. Other people on the WiFi cannot read the
                administrator password. The box's certificate authority is
                limited to this box's names. A device that enforces the limit
                rejects other sites.

              Transport
              
                    
            
                    
            
                    
              Administrator access over HTTP
              
                    
            
                    
            
                    
            
                    
            
                    
            
                    
              
                Use your own certificate
              
              
                    
                Use this for a domain that you own, with a certificate made
                elsewhere. The box has no public address, so use a DNS
                challenge:
                certbot certonly --manual --preferred-challenges dns, or the tool of your DNS host. Devices then trust the box
                without an installation. Paste the full chain (the certificate,
                then its intermediates) and the unencrypted private key. The box
                checks that the certificate and key match, that the certificate
                has not expired, and that the chain reaches a known CA. The box
                never replaces the certificate by itself. Renew it before it
                expires.
              
                    
              
                    
                This page uses plain HTTP. The private key would cross the
                network in clear text. Paste the key over HTTPS.
