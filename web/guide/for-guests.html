📖 Using the hub

For everyone on the box's network.

The hub is the box's front page. It needs no internet: everything here stays on the box, for the people around it.

  • The tiles open each app: drawing (Excalidraw), diagrams (Mermaid), the file drop, the offline library (Kiwix), shared notes (and, once signed in, a notebook of your own), calculators, chat and more, as the owner set it up. Some open for everyone, some for signed-in users only (with a padlock).
  • The shoutbox and the board: short messages, and threads, for everyone on the hub. Report anything that shouldn't be there; the owner decides.
  • The file drop: leave files for others, and take theirs. A file can be locked to your browser, so only you can change or remove it.
  • 👤 Sign in if the owner has given you an account, or if the box lets anyone make one. Your account page has your own settings.
  • 🛟 Help says what each app is for.
  • The theme picker at the top: light (☀️), dark (🌙) or Auto (as your device is set); and under 🎨, the colours: the Box preset (the owner's, the default), Standard, Increased contrast, or a theme of its own colours (E-ink, Cybercore). Your choice stays in your browser.

Privacy

Without an account, a page asks for any name. The box does not check that name. With an account, your username identifies you.

HTTP does not encrypt traffic. Others on the same WiFi can read what you type. Use HTTPS for passwords and private information. The box's certificate page (/certificate) shows how to trust the box. Check that page before you trust the box.
