📖 Glossary

Words that the box pages use.

TermDefinition
AccessWho can open an app or page: Guests, Users, Administrators or Disabled
AccountA user or administrator account that can sign in
Add-onAn extra that an administrator can add or remove: Kiwix, Notes, Syncthing and others
AdministratorA person with an administrator account. An administrator can change the box settings
AppearanceThe icon, the label and the size of a tile, and the colours of the hub
BookAn offline reference in the ZIM format. Kiwix reads it
CacheA local copy of a downloaded file that the box keeps
DiscardThrow away changes that you did not save
DoctorA page that checks one part of the box, lists the problems and offers repairs
GuestA visitor without an account
HotspotThe WiFi network of the box
Hotspot service accessWhat guests on the hotspot can reach on the box (also called the floor)
HubThe front page of the box and the program behind it
Initial setupThe state of a new box before an administrator account exists. Until an administrator creates the account, anyone on the network can open the administration pages
InstallPut a downloaded package or add-on into use
MirrorA copy of a repository from another server, kept on the box
Recovery stepsThe repairs of the network watchdog, from the lightest to the heaviest (also called the ladder)
Retention periodThe time that the box keeps an item before it deletes it
SaveKeep the changes that you made
Sign inOpen a session with your account
Storage limitThe largest amount of storage that an item can use
ToolkitA set of packages for one kind of job. Install it without internet if all its packages are in the cache
UpdatesNew versions of the box, apps, books and packages
UserA signed-in person who has an account
User dataShared files, drawings, posts and repositories
VisibilityWho can see a tile on the hub
