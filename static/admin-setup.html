Set up

Step 1 of 5: choose the admin password for this box.

This box has no admin password yet. Whoever sets it here owns the box: the admin page, the terminal at /term and Syncthing at /sync all use it, with the user name admin.

Anyone on this network can open this page until a password is set, so set it now. If you are a guest, not the owner, please leave this alone.

After this, the admin page takes you through the rest: how guests reach the box, what it exposes, add-ons and books. Each of those can be skipped and done later.

Lost it later? From the box's own console: sudo python3 /opt/irate-box/hub_control.py reset-password brings this page back.
