Remote access

Tailscale lets you reach the box from anywhere. While it is off, it can only be switched back on from here — so from the hub's own WiFi or LAN, not remotely.

Sync

Syncthing — an optional add-on for moving notes and content between the box and your own machines when they share a network. Returns an error page if it is not installed or its unit is off.
