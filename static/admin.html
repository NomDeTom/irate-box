Box and services

Optional services can be started, stopped, or set to start at boot. Caddy and the hub can only be restarted. Each change is carried out by a small root helper on the box, so it takes a second or two to show here.

Library

The librarian keeps books in /wiki/ up to date from where they are published. Each book keeps its name across versions, so links into it never break; older versions are archived or deleted as set below. Books added by hand, or by install.sh --zim, are left alone unless a source here has the same name.

GitHub token

Only for "GitHub Actions artifacts": GitHub requires a login to download those, even from public repositories. A fine-grained token with read-only access to public repositories is enough. Stored on the box, readable only by the hub; never shown again.

Moderation

Everything here also ages out by itself: shoutbox messages after 24 hours, board threads 7 days after their last reply (powered-on time). Deleting is immediate and permanent.

Remote access

Tailscale lets you reach the box from anywhere. While it is off, it can only be switched back on from here — so from the hub's own WiFi or LAN, not remotely.

Housekeeping

Installed: …

Download a backup of the hub's state: notes, saved work, board, shoutbox, settings, the library's sources and the uptime clock. ZIM books and archived versions are left out (they come from their sources), as is the GitHub token.

Syncthing — an optional add-on for moving notes and content between the box and your own machines when they share a network. Returns an error page if it is not installed or its unit is off.
