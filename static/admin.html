Add-ons

        

          The hub works without any of these. Adding one installs it and starts it; removing one
          stops it and takes its service away, and keeps its data, so adding it back finds
          everything where it was. Each runs the installer, which takes a few minutes on this
          board and restarts the hub part-way through.

Access

        
Admin password

        

          The one login for /admin, /sync and /term (user admin), and Syncthing's own.
          After changing it, the browser asks for the new one.
        

        

          
          
          
        

        


        

          
Remote access

        

          Tailscale lets you reach the box from anywhere. While it is off, it can only be
          switched back on from here — so from the hub's own WiFi or LAN, not remotely.

Apps

        

        
        

          The whiteboard, the Mermaid editor, the serial terminal and the collaboration relay come
          from their forks' GitHub Actions builds, and the calculators from their repository, adapted
          for the hub. Which apps there are is set by the manifests in apps.d/.
        

        

      


      

        
Books

        

        
        

          The librarian keeps the books in /wiki/ current from where they are
          published, on the schedule under Schedule and token.
        

        

          Each book keeps its name across versions, so links into it never break. Books added by
          hand, or by install.sh --zim, are left alone unless a source here has the same
          name.

From or to a USB stick

        

          Plug a stick into the box, then scan. Books on it can be copied into the library, and the
          hub's books copied onto it to carry to another box. The stick is only mounted for the
          scan or the copy, read-only unless something is being copied to it.
        

        

        

        

          
          

        

        

      


      

        
Firmware

        

          Meshtastic firmware kept on the box for the web flasher, so a radio can be flashed with no
          internet. Only the boards you tick are kept (a few MB each, per release); "all boards" is
          about 600 MB a release. Checked on the library's schedule, whenever the box has internet.

GitHub token

        

          Only for "GitHub Actions artifacts": GitHub requires a login to download those, even from
          public repositories. A fine-grained token with read-only access to public repositories is
          enough. Stored on the box, readable only by the hub; never shown again.

Git

        

          Two git servers on this box. /git/ is public: anyone on the network can
          browse and clone, and pushing needs the admin login unless guests may push.
          /git-private/ is behind the admin login for everything.
          Clone with git clone http://<this box>/git/<name>.git; git asks for the
          login when it is needed.

        Security
        
        
        
          What a guest on the box's network can reach, and how the box is set up. Nothing here
          changes until you press its button. Every change can be undone here, and uninstalling
          irate-box puts back what it found.

          The hotspot's own WiFi
          
        
          
          How guests join the box's own hotspot: open to all, or encrypted so someone listening nearby
          cannot read what guests do. Encryption shuts out older devices, so this is a trade between
          who can join and what is protected. The hotspot itself is still to come (the hotspot add-on):
          the choice is kept and applied when it is set up. What the radios here allow comes from
          Network.

            Security doctor
            
        
            
          A read-only audit of how the system underneath is set up, including what the hub found
          when it was installed: the notes add-on, the web server's settings, links and root-written
          files in the hub's folders, unit sandboxing, secrets on command lines and at rest, git
          pushes, sudo rules, accounts and the kernel's protections. It changes nothing and has no
          buttons beyond this one; each line says what to do by hand. Also from a shell:
          sudo python3 /opt/irate-box/secdoctor.py.

                  When an update fails
                  
        
                  
          The update doctor looks at what an update depends on — the network, names, the clock,
          GitHub, free space, the cached copy, the package sources — and says what is wrong and what
          to do about it. For the box itself (services, Kiwix, an install that stopped), see
          Health.
        
                  
        
                  
          
          
        
                  
        
                  
        
                  
        
                    
      
                    

      
                    
        
                    Backup and sync
                    
        
                    
          Download a backup of the hub's state: notes, saved
          work, board, shoutbox, settings, the library's sources and the uptime clock. ZIM books
          and archived versions are left out (they come from their sources), as is the GitHub token,
          and so is Syncthing's identity: restored, Syncthing gets a new device ID and its peers
          pair again.
        
                    
        
                    
          ⚠ Includes Syncthing's private keys:
          download a backup with
          Syncthing's identity (key.pem, https-key.pem,
          config.xml), so a restored box keeps its device ID. Whoever holds that file
          can pose as this box to its Syncthing peers: keep it like a password.
        
                    
        
                    
          Syncthing — an optional add-on for moving notes and
          content between the box and your own machines when they share a network. Returns an error
          page if it is not installed or its unit is off.
